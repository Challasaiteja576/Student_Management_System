# Student Management System | Python

## Project Overview
The Student Management System is a menu-driven Python application developed using Object-Oriented Programming (OOP) concepts and File Handling. It helps users manage student records efficiently by performing basic CRUD (Create, Read, Update, Delete) operations.

## Features
- **Add Student:** Add student details such as ID, name, age, and place.
- **View Students:** Display all registered student records.
- **Search Student:** Search for a student using their unique ID.
- **Update Student:** Modify existing student information.
- **Delete Student:** Remove student records using their ID.
- **File Handling:** Store student records in a text file (`student.txt`) for data storage.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors (`__init__`)
- Lists
- File Handling
- Functions and Loops
- Conditional Statements
